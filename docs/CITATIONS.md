# Asset and reference record

This file records external assets and technical references intentionally used by the project. It is not a license grant for third-party material.

## Current repository assets

- Procedural geometry in `scenes/` and `scripts/` — generated at runtime from project source code; no external 3D asset license is claimed for these primitives.

## Third-party assets

No third-party Marketplace asset is currently recorded as part of the verified baseline. Do not add an external asset to the repository unless its source, license, attribution requirements, and redistribution terms have been checked first.

When an external asset is added, record at minimum:

1. asset name and version;
2. exact source URL;
3. creator/publisher;
4. license or marketplace usage terms;
5. required attribution;
6. redistribution permission;
7. repository path where it is used.

If redistribution rights are unclear, do not commit the asset.
